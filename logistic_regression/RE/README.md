Logistic Regression from Scratch and Scikit-Learn
This project is an educational deep dive into Logistic Regression. It explores the fundamental concepts of classification by building a model to categorize clients (VIP vs. Not VIP) based on their age and years of education. The goal of this project is to understand the mathematical transition from Linear Regression to classification algorithms.

🚀 Project Overview
The project is divided into practical, step-by-step phases:

Data Exploration: Loading and visualizing the dataset using matplotlib to understand the distribution of VIP vs. non-VIP clients.

Mathematical Foundations: Manually implementing the Sigmoid Function and exploring how Linear Regression can be adapted for classification.

Model Implementation: Building the Logistic Regression model using scikit-learn.

Prediction & Probability: Testing the model with custom inputs and utilizing predict_proba to interpret confidence levels.

🛠 Tech Stack
Python

Pandas: Data manipulation and analysis.

Matplotlib: Data visualization.

Scikit-learn: Machine learning model implementation.

📁 Repository Structure
logistic_regression.ipynb: The Jupyter Notebook containing the full implementation and explanations.

income12.csv: The dataset used for training and prediction.

📥 How to Run
Ensure you have the necessary libraries installed:

pip install pandas matplotlib scikit-learn

Open logistic_regression.ipynb using Jupyter Notebook, VS Code, or Google Colab.
