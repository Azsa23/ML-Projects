# 🏦 Loan Eligibility Prediction (Decision Tree)

A machine learning project to predict loan approval eligibility based on applicant profiles using the **Decision Tree Classifier** from `scikit-learn`.

## 📌 Project Overview
* **Exploratory Data Analysis (EDA):** Overview of loan applications, summary statistics, and missing value distribution.
* **Data Preprocessing:** Handling missing values and encoding categorical attributes into numerical formats.
* **Class Balancing (Resampling):** Upsampling the minority class to achieve a balanced class distribution.
* **Model Training & Evaluation:** Training a `DecisionTreeClassifier` and evaluating performance using Accuracy, Precision, Recall, F1-Score, and a Confusion Matrix heatmap.

## 🛠 Tech Stack
* Python 3.x
* Pandas
* Matplotlib & Seaborn
* Scikit-Learn

## 📊 Results
* **Accuracy:** ~84%
* **Precision:** ~90%
* **Recall:** ~77%
* **F1-Score:** ~83%
